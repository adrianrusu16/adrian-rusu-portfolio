# Portfolio editing rules

- Keep Astro static output and TypeScript. Use client JavaScript only for needed interaction.
- Maintain the typed Markdown project collection as the source of truth for project metadata.
- Keep one h1 per page, semantic landmarks, visible keyboard focus, responsive diagrams, and reduced-motion behavior.
- Do not invent employment history, contact information, benchmark results, repository URLs, or implementation status.
- Do not publish proprietary commercial screenshots, traces, internal APIs, or customer details.
- Run `pnpm check`, `pnpm lint`, `pnpm format:check`, `pnpm build`, and `pnpm test` before delivery.
- Use feature/fix branches when appropriate and conventional commit messages.
- Read `.openai/hosting.json` before any Sites operation; preserve the existing project identity and audience.
